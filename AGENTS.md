# Инструкции Codex / Cursor

## Обязательные правила работы с репозиторием

- Код писать только после явного «утверждаю» пользователя под соответствующим `SPEC.md`.
- Одна задача из `SPEC.md` — один коммит. В сообщении коммита указывать номер задачи.
- К каждой задаче добавлять тест. Перед каждым коммитом запускать все тесты.
- Если реализация отличается от `SPEC.md`, сообщить об этом пользователю до коммита.
- Ключи и токены в репозиторий не коммитить.

Эти правила установлены пользователем 2026-11-08; «ок» не заменяет «утверждаю». При расхождении с другими проектными документами применять эти правила. Они не приписывают одобрение предыдущим изменениям задним числом.

## Остальные документы проекта

Если в рабочей копии есть `CLAUDE.md`, перед работой прочитать его и документы, на которые он направляет. Обязательные правила выше действуют и без локального брифинга.
