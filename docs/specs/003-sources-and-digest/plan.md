## Общие ограничения

- Exa — независимый канал существующего коллектора, без отдельного сервиса и обязательного приоритета. Общий лимит $5/месяц, $0,05/вопрос и $0,05/суточный запуск, включая Search/Contents/повторы. Модель учитывается отдельно.
- Старые Europe PMC/PubMed не вызываются в новом пути; device/event и каталоги не используются для научного вопроса. Старые данные и настройки других источников сохраняются.
- Только публичные страницы без обхода сетевой защиты; AAD/Cochrane при недоступности откладываются, статус виден; замену не назначать автоматически. После деплоя проверка через приложение, без ручного терминала.
- Тесты без внешних API, сообщений и расходов; PostgreSQL только отдельная локальная тестовая. Перед каждым коммитом все Python/Web/имеющиеся JS тесты, компиляция и diff-check, независимая роль C и проверка состава/секретов.
- После каждого шага обновить задачи и progress. Деплой и внешняя живая приёмка остаются отдельно согласованными действиями.

## SRC-003 — коллектор и расходы

3. `collect/search` принимают необязательные `purpose='question'|'daily'`, `scope_id`, возвращают прежние processed/failed_sources плюс material_ids/checks. Для прямых источников ограниченные собственные публичные URL/индексы; Exa не обнаруживает их обязательным образом.
