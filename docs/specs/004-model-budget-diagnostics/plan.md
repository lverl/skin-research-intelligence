# План FIX-006

Основание: [утверждённая спека](spec.md). Одна задача, один коммит; публикация и деплой отдельно.

1. A/root добавляет `llm.budget_summary(conn)` с одним SELECT по неизменному месячному окну текущего учёта. Возвращаются Decimal-суммы известной стоимости/неизвестных резервов, число неизвестных вызовов, итог, лимит/следующий резерв/остаток и финансовая причина блокировки. Без резервирования, записи или HTTP.
2. A/root показывает эту сводку в существующем `/status` только владельцу из OWNER_TELEGRAM_ID. Данные описаны как учёт приложения; существующие ответы остальным пользователям сохраняются.
3. B/prd_sources_review независимо дополняет только tests/test_budget.py и tests/test_telegram.py: контрольные суммы из спеки, нулевая стоимость и доступ владельца. Не добавлять другие функции или диагностические направления.
4. C/clarification_verify запускает весь существующий Python/web/JS-набор на отдельной PostgreSQL, проверяет read-only и приватность. После устранения реальных замечаний — один коммит FIX-006, без push/деплоя.
