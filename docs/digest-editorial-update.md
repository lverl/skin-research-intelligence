# Уточнение дайджеста · 2026-11-02

Редакционная версия 3: карточки Open Beauty Facts, коммерческие материалы и отдельные отчёты MAUDE исключены до обращения к модели. Эти записи остаются в базе. Генерация и проверка получили запрет рекламных анонсов и выводов об эффективности из состава; сообщения о безопасности допускаются для официальных предупреждений, отзывов и изменений рекомендаций с понятной связью с уходом. Сегодняшний выпуск прежней версии пересобирается один раз. Новые источники предупреждений этим изменением не подключаются. Проверено 60 автономных тестов и 5 web-тестов; 5 PostgreSQL-тестов пропущены.

Последующее согласованное упрощение: Telegram показывает до пяти пунктов в сообщении, кликабельный короткий пересказ, существенные ограничения, название источника и ссылку. Отдельные блоки практического значения скрыты. Команда /digest применяет формат и к уже сохранённому выпуску без повторных модельных вызовов. Для новых выпусков задан пересказ в 1–2 предложениях. Проверено 57 автономных тестов, 5 PostgreSQL-тестов пропущены.

По согласованию с пользователем изменены только инструкции отбора, проверки и формат Telegram. Приоритет — материалы с понятной связью с уходом, исследования на людях, безопасность, средства и ингредиенты. Лабораторные протоколы без обоснованной связи с уходом исключаются; перенос результатов животных и клеток на человека запрещён. Заголовки — на русском, пункты содержат находку, смысл для ухода, ограничения и ссылки. История версий выводов остаётся в базе и не выводится в Telegram.

Редакционная версия 2 пересобирает сегодняшний старый выпуск один раз, включая ранее отобранные материалы. Увеличение revision запускает существующую повторную доставку. Если подходящих материалов нет, сохраняется честный пустой статус; последующие новые обработанные материалы могут обновить его. Прошлые дни не пересобираются. Сбор и схема базы не изменены.

Проверено: 55 автономных тестов и 5 тестов web прошли; 5 PostgreSQL-тестов пропущены без тестовой БД. Живая генерация моделью и доставка на сервере требуют проверки после деплоя.
