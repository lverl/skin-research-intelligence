# Канбан проекта

Единый бэклог функций, исправлений и идей. ID сохраняется при перемещении карточки. Для функции указывать PRD, стадию SDD, spec/plan/tasks, исполнителей и основание завершения.

Стадии: Идея → Опрос → Spec на одобрении → План → Готово к коду → Реализация → Независимые тесты → Проверка результата → Done. Дополнительный статус: Отложено.

Версии: новые релизы пока не назначены. При выборе следующей версии согласовать с пользователем цель и набор карточек; записать номер версии в её карточки и spec/tasks. Карточки ниже не являются обещанием состава ближайшего релиза.
